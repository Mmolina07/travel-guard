# HU-05: Crear Viaje

## Enunciado de la Historia
- **Rol:** Como turista.
- **Característica:** Necesito crear un viaje registrando sus detalles principales: destino, fechas, número de personas, hospedaje, transporte y presupuesto.
- **Razón / Resultado:** Con la finalidad de planificar y presupuestar mi viaje.

## Criterios de Aceptación (Escenarios)

### Escenario 1: Crear Viaje con Todos los Datos
- **Dado que** estoy en el formulario de crear viaje
- **Cuando** ingreso: Nombre, destino, fecha inicio, fecha fin, número de personas, tipo de viaje (vacaciones/trabajo/ocio/otro), presupuesto máximo, pagos anticipados, tipo hospedaje, costo hospedaje, servicios incluidos (desayuno/almuerzo/cena/traslado), transporte inicio/durante (carro/transporte público/Uber/vuelo), tours con guía, restaurantes, discotecas, souvenirs, actividades pagas, dinero emergencias
- **Entonces** el sistema guarda el viaje y me muestra un resumen con presupuesto total

### Escenario 2: Validar Fechas Válidas
- **Dado que** estoy llenando el formulario de crear viaje
- **Cuando** ingreso fecha de fin anterior a fecha de inicio
- **Entonces** el sistema muestra error "La fecha de fin debe ser posterior a la fecha de inicio"

### Escenario 3: Validar Número de Personas
- **Dado que** estoy llenando el formulario
- **Cuando** ingreso 0 o número negativo en personas
- **Entonces** el sistema muestra error "Debe haber mínimo 1 persona"

### Escenario 4: Validar Presupuesto
- **Dado que** estoy llenando el formulario
- **Cuando** ingreso presupuesto negativo o 0
- **Entonces** el sistema muestra error "El presupuesto debe ser mayor a 0"

### Escenario 5: Validar Costos de Hospedaje
- **Dado que** estoy llenando el formulario
- **Cuando** ingreso costo de hospedaje negativo o 0
- **Entonces** el sistema muestra error "El costo debe ser mayor a 0"

### Escenario 6: Validar Dinero de Emergencias
- **Dado que** estoy llenando el formulario
- **Cuando** ingreso dinero de emergencias negativo o 0
- **Entonces** el sistema muestra error "El monto debe ser mayor a 0"

### Escenario 7: Campos Obligatorios Incompletos
- **Dado que** estoy llenando el formulario
- **Cuando** intento guardar sin completar campos obligatorios (básicos)
- **Entonces** el sistema muestra "Debe completar todos los campos obligatorios"

### Escenario 8: Crear Viaje con Datos Parciales
- **Dado que** estoy llenando el formulario
- **Cuando** completo datos básicos pero dejo campos opcionales vacíos
- **Entonces** el sistema me muestra: "La estimación será menos precisa. ¿Deseas continuar?"

### Escenario 9: Confirmar Creación Parcial
- **Dado que** veo el aviso de datos incompletos
- **Cuando** confirmo "Sí, crear viaje"
- **Entonces** el sistema crea el viaje y permite editarlo después

### Escenario 10: Cancelar Formulario
- **Dado que** estoy llenando el formulario
- **Cuando** hago clic en "Cancelar"
- **Entonces** el sistema me muestra "¿Estás seguro?" y si confirmo, descarta los datos

### Escenario 11: Eliminar Viaje Creado
- **Dado que** estoy viendo un viaje creado
- **Cuando** hago clic en "Eliminar viaje"
- **Entonces** el sistema muestra "¿Estás seguro?" y si confirmo, lo elimina
